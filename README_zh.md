# Rubato

**在浏览器里用 Claude Code —— 解压，双击 `start.bat`，就这样。**

[English](README.md) | 中文

Rubato 把 Claude Code / Codex 包成一个网页版的多会话任务中心。
它最想解决的不是「多开几个会话」，而是**让完全没配过环境的人也能真的用起来**。

---

## 你不需要先装任何东西

这是 Rubato 和其他同类工具最大的区别：**装环境这件事，它自己来。**

| 别人要你先做的 | 在 Rubato 里 |
|---|---|
| 装 Node.js、配 PATH | 没有就自动下一份便携版，只放在软件自己的目录里 |
| `npm install -g @anthropic-ai/claude-code` | 引导页点一下「立即安装」，带实时进度条 |
| 装 Git | 同上，Windows 免管理员、不写注册表 |
| 打开终端跑 `claude` 登录 | **网页里点按钮登录**：给你链接、给你四步指引、授权码粘回来就好 |
| 自己判断「为什么没反应」 | 先做**网络体检**，连不上 Claude 会直接告诉你为什么、怎么办 |

所以真实的上手路径就三步：

```
① 解压  →  ② 双击 start.bat（macOS / Linux 跑 ./start.sh）  →  ③ 跟着网页里的引导走完
```

引导一共五步：语言与外观 → **网络体检** → 选引擎 → 选模型服务商 → **登录账号 / 填 API Key**，
每一步缺什么都能当场装、当场修，不会把你丢在一个「什么都没发生」的空白界面里。

---

## 连不上 Claude？这里不会只丢给你一句报错

国内用户十有八九卡在这一步。Rubato 在引导的第二步就把它查清楚，并且**当场给两条出路**：

- **开科学上网** → 点「我已开启，重新检测」；
- **完全不翻墙** → 直接切换到国产大模型（MiniMax / Kimi / 小米 MiMo），
  界面上只会列出**当时实测能连通**的那几家，点一下就切过去。

体检不是猜的：它并发探测国内外基准站点、Claude 官方端点和各家国产端点，
只看「有没有 HTTP 响应」（`api.anthropic.com` 裸访问本来就返回 401/405，那正是连得上的证据），
并且**会跟随你的 `HTTPS_PROXY` 走隧道探测** —— 否则已经开了代理的人会被误报成「不通」。

## 网页里完成 Claude 登录

原版 Claude Code 必须先登录账号，否则你发出去的消息**不会有任何回应，也不报错**。
Rubato 把这一步搬进了网页：

1. 点「开始登录 Claude」，后端起一次官方登录流程并抠出授权链接；
2. 页面给你一个大按钮 —— 点开就是 Claude 授权页；
3. 在浏览器里登录并点 Authorize，页面会给你一串授权码；
4. 把授权码粘回输入框，点「完成登录」。

**服务器装在远端也照样能用**：链接是在你自己的浏览器里打开的，授权码手动粘回来即可。
已经在别处登录过、或者用的是第三方 API Key？界面会明确写「无需登录」，不会让你白折腾。

## 还有什么

- **多会话 / 任务队列**：一个会话排一串任务，自动依次执行；可暂停、插话、重排、批量删。
- **全过程可见**：AI 的思考、每次工具调用的完整入参与输出、耗时与 token，都能展开看。
- **文件管理器**：按工作目录浏览、在线编辑、搜索、收藏重点文件夹。
- **失败必可见**：引擎启动失败、退出码 0 却零输出、长时间没反应，都会在界面上给出原因和处置建议，
  而不是安静地什么都不发生。
- **跨平台**：Windows / macOS / Linux 一套代码，安装路径按平台自动分流
  （mac 走 brew，Linux 依次探 apt/dnf/yum/zypper/pacman/apk，没有 root 就把该敲的命令原样给你）。
- **源怎么选？实测，不猜**：你自己配过 npm 源就用你的；没配过就并发探测官方源与国内镜像，谁快用谁。

## ⚠️ 安全须知（务必先读）

Rubato 会在你的机器上**以跳过权限确认的模式（`bypassPermissions`）启动 Claude Code / Codex 子进程**，
以便无人值守地连续执行任务。这意味着：

> **任何能访问这个网页界面的人，都能在你的机器上以你的身份读写任意文件、执行任意命令。**

因此：

1. **默认只监听 `127.0.0.1`**，请保持这一默认值。设置里的「允许局域网访问」会绑定 `0.0.0.0`，
   只在你信任所处网络时开启。
2. **绝对不要把本服务直接暴露到公网**。需要远程访问请走 SSH 隧道或 VPN，并务必配 HTTPS。
3. **访问口令由你首次打开界面时自行设定**。本项目**不含任何内置或默认口令**，
   口令以「随机盐 + sha256」保存在 `projects/claude_hub/data/auth.json`（已被 gitignore）。
   请设一个足够强的口令 —— 它是唯一挡在任意命令执行前面的东西。
4. **API Key 由你自己在界面「设置」里填写**，只存在本地 `data/` 下，不入库。仓库内不含任何密钥。
5. `data/` 目录含会话记录、密钥与本机设置，**不要提交，也不要打包分享**。
6. 多用户主机上请注意：本服务不区分用户，一个口令即全部权限。

发现安全问题请提 issue（或私下联系维护者），不要公开可利用细节。

## 启动 / 停止

| 平台 | 启动 | 停止 |
|---|---|---|
| Windows | 双击 `start.bat` | 双击 `stop.bat` |
| macOS / Linux | `./start.sh` | `./stop.sh` |

`start` 脚本自己会做完整自检：Node 够不够新、依赖装没装、`backend/dist` 是不是比源码旧、
`data/` 能不能写 —— 缺什么补什么，然后打开 <http://localhost:8970>。

macOS / Linux 首次使用先给执行权限：

```bash
chmod +x start.sh stop.sh
./start.sh
```

> macOS 提示「无法打开，因为它来自身份不明的开发者」时，请在**终端**里运行 `./start.sh`
> （不要在 Finder 里双击），或在「系统设置 → 隐私与安全性」中放行。

其他细节：

- 端口 8970 被占用时，`start` 会**自动先跑一遍 stop 释放端口**再继续启动；仍被占才停下来报错并打印占用进程。
- 服务异常退出时窗口会保留并打印退出码，不会一闪而过。
- 服务器上常驻运行（需要 pm2）：`cd projects/claude_hub && bash restart.sh`。

## 项目结构

```
projects/claude_hub/
├── backend/src/
│   ├── logic_struct/    # 调度层：只写「用了谁、什么顺序」的骨架
│   ├── logic_realize/   # 实现层：继承 Struct，填具体怎么做
│   ├── helper/          # 纯工具，与业务无关、可独立测试
│   └── server/          # HTTP + WebSocket 路由
├── frontend/            # 静态前端，无需构建
├── out_end/             # 便携运行时（按需下载，不入库）
└── data/                # 会话、密钥、设置（不入库）
```

代码遵循 Struct / Realize 分层：**「做什么」和「怎么做」分开写**，
调度骨架一眼能读完，实现细节改起来不会误伤架构。详见 `docs/SYSTEM_zh.md` 与架构图 `docs/architecture.svg`。
