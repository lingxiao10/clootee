xfeixie-assistant

一行代码，给任意网页加一个能看懂这一页的 AI 小助手。单文件 · 零依赖 · 不需要后端。

这一页自己就装着它。看右上角 —— 点开就能用。 随便选中本页的一段文字，会浮出「问小助手」。

怎么用

在你的网页 </body> 之前加这一行，完事：

<script src="https://learn.xfeixie.com/assist/assistant.js"></script>

不需要写 HTML 容器，不需要引 CSS，不需要初始化代码。

它能做什么

  • 固定在右侧，可收起展开
  • 使用者自己填 MiniMax API Key，只存在他自己的浏览器里
  • 多轮对话，支持新建会话 / 切换 / 删除
  • 能看见整个网页：提问时自动把本页正文一起发给模型
  • 划词提问：选中任意文字 → 浮出按钮 → 那段话作为引用一起发出
  • 20 轮红字提醒换会话，40 轮锁定输入（每轮都要重发全部历史，越聊越贵）

配置（可选）

<script>
  window.XFAssistant = {
    title:   '学习小助手',
    subject: 'GEO 搜索引擎优化',   // 本页主题，回答更贴题
    lang:    'zh',                // zh / en，不填跟随浏览器
    accent:  '#5b8cff'
  };
</script>
<script src="https://learn.xfeixie.com/assist/assistant.js"></script>

要发给别人 / 要能双击打开

把 assistant.js 下载到教程 HTML 旁边，改成相对路径：

<script src="./assistant.js"></script>

这样整个教程就是一个能随便拷贝的文件夹，断网也打得开（只有提问那一步需要联网）。

给 AI 看的文档

如果你在用 Claude Code / Codex 这类 AI 生成教程，把这个地址给它读：

https://learn.xfeixie.com/assist/docs.md

它会知道怎么正确接入，不会自己再造一个聊天窗。

隐私

  • Key 只存在使用者浏览器的 localStorage
  • 请求由浏览器直接发给 MiniMax，不经过本站或任何中间服务器
  • 会话记录也只在浏览器本地，每个页面路径各存各的

领 MiniMax Key：platform.minimaxi.com/console/plan
