快捷按钮

          

            在输入框上方显示一排可点的快捷按钮。每个按钮对应一段含义（提示词）：选中后发送时会自动加到正文最前面；含义留空则退化为在正文前加 [按钮文字] 前缀。

            同一「分组」内的按钮互斥（只能选 1 个，再点一次取消）；不同分组互不影响，可各选一个。想要单个独立按钮时，新建一个只放一个按钮的分组即可。热键 Ctrl+1..9 按按钮整体顺序对应。
          

          

          
        


        
        

          

            对话越长，塞给模型的上下文越多。逼近上限时 Claude Code 会把前面的内容压缩成摘要再继续，这样会话能一直聊下去而不报「上下文超长」。

            压缩发生时，过程区会出现一行 [上下文自动压缩] 提示。
          

          
          
          

            
            
            
上下文用到这个量级就触发压缩。调小＝压得更早更频繁、每次请求更省；调大＝保留更多原文，但要求模型确实支持这么长的上下文，否则会直接报错。
