# AGENTS 指南 · 日常办公

面向自动化代理的协作约定，与本目录 `CLAUDE.md` 一致，请同步维护。本目录是**办公工作区**（文档、表格、报告、数据整理），不是代码项目。

## 开始前 / 结束后
- 任务前读根目录 `mem.md`；完成后把进展、结论、口径取舍写回 `mem.md`。

## 硬性约定
- 目录：`输入/`（原始素材，只读）、`输出/`（交付成品）、`草稿/`（中间过程）。文件名 `YYYYMMDD_主题_版本`。
- 不覆盖、不删除原始文件；改动一律另存新版本，破坏性操作前先说明。
- 口径不清（时间范围、统计口径、受众、篇幅）先问一句再动手。
- 报表与结论中的关键数字必须可追溯到源文件与算法；不确定处显式标注，禁止编造。
- 多步数据处理走脚本并保留在 `草稿/`，保证可复跑、可复核。
- 文档结论先行，能用表格清单就不写大段文字；标点、金额、日期、单位格式全篇一致。
- 对外发送内容（邮件/通知/公告）只出草稿，不代为发送。
- 敏感信息（人名、电话、证件号、薪酬）不外泄、不进示例，必要时脱敏。

## 完成标准
- 成品在 `输出/` 且命名规范；关键数字已复核；`mem.md` 已更新；回复中说明改动的文件与待确认事项。
